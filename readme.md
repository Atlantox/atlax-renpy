# Atlax Renpy

Atlax Renpy es un motor de videojuegos de estilo novela visual con una única filosofía.

# Hazlo más sencillo

Este motor funciona utilizando archivos de control en formato CSV que están conectados entre sí. Estos archivos contienen los diálogos, cambios de fondo, canciones, efectos de sonido, efectos de la pantalla y por supuesto, los movimientos de los personajes.

Todo esto mediante mínimos conocimientos informáticos y de programación. A efectos prácticos crearás tus novelas visuales utilizando Excel.

# Trabaja en conjunto

Atlax Renpy permite que múltiples escritores trabajen en simultáneo en sus respectivas escenas o rutas. ¿Lo mejor de todo? A medida que vayan escribiendo, tendrán la capacidad de ver cómo se comporta el juego tal cual como lo vería un jugador final.

# Maneja decisiones y consecuencias

Crea todas las decisioens y ramificaciones que necesites. ¿Tu novela trabaja con puntos de amistad? ¿Quizás utiliza puntos de fuerza, inteligencia, etc? ¡No hay ningún problema! con Atlax Renpy puedes definir las putuaciones que requieras y crear consecuencias.

Por supuesto que también puedes crear consecuencias basadas en decisiones pasadas o en escenas vistas. ¡Puedes bifurcar tu historia tanto como necesites!

# ¿Cómo instalarlo?

1. Descarga el release más reciente de Atlax Renpy [aquí](https://github.com/Atlantox/atlax-renpy/releases)
2. Descomprime el archivo .zip
3. Obtendrás un instalador .exe y el manual del motor .pdf
4. Mueve el instalador a un proyecto recién creado en Renpy.
5. El instalador debe estar en la carpeta raíz del proyecto, al mismo nivel que la carpeta game (NO ADENTRO)
6. Ejecuta el instalador y creará el sistema de carpetas y scripts necesarios para funcionar.
7. Lee el manual de Atlax Renpy.

¡Ojo! Atlax Renpy está altamente optimizado para la escritura de novelas visuales, si deseas implementar minijuegos o mecánicas más concretas, tengo algo que decirte...

¡Por supuesto que puedes! Con este motor puedes crear tus propios scripts personalizados en lenguaje Renpy y conectarlo con uno o más archivos de control creando así un flujo de trabajo híbrido entre Atlax Renpy y lenguaje Renpy.
